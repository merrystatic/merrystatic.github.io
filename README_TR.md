# MERRY STATIC Games Studios — GitHub Pages

## Siteyi yayınlama
1. GitHub hesabında https://github.com/new adresini aç.
2. Depo adını `merry-static-games` yap, Public seç ve Create repository tıkla.
3. ZIP içindeki dosyaların tamamını **deponun kök dizinine** yükle (ZIP dosyasını tek başına yükleme). `assets/` klasörü de yüklenmeli.
4. Commit changes ile kaydet.
5. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save.
6. Yayın adresi: https://arslan147896.github.io/merry-static-games/ (yayın etkinleştirildikten sonra).

## Güncelleme
Yeni oyun için `games.js` içine bir kayıt ekle ve logoyu `assets/` klasörüne koy.
`status: "soon"` yakında, `status: "live"` yayında demek.
`googlePlay` veya `appStore` bağlantıları ilgili alanlara yazılır.
8 dilde yeni oyun açıklaması için `translations.js` içindeki 8 dilin `games` bölümüne oyunun kimliğine ait çevirileri ekle.

Varsayılan dil Türkçedir, kullanıcı dil seçimini cihazında saklar.

Not: GitHub Pages kaynakları herkese açık yayımlanır; özel veri, API anahtarı veya parolalar yüklemeyin.
